# BMS 난이도표 다운로더

**한국어** · [日本語](README.ja.md) · [English](README.md)

6개 BMS 난이도표에서 표와 레벨을 고르고 BMS Library에서 곡 본체와 차분을 검색한 뒤, 서버 제한에 맞춰 순차적으로 다운로드를 요청하는 다국어 북마크 도구입니다.

## 빠른 설치

1. [설치 페이지 열기](https://yuupmu.github.io/BMS_starlight_difficulty_downloader/)
2. 북마크바가 보이지 않으면 `⌘/Ctrl + Shift + B`를 누릅니다.
3. 설치 페이지의 **★ BMS Table Downloader** 또는 **★ Standalone Downloader** 버튼을 북마크바로 드래그합니다.
4. [BMS Library Songs](https://horieyuuka.github.io/Songs)를 열고 방금 추가한 북마크를 클릭합니다.

GitHub README에서는 브라우저 보안 때문에 `javascript:` 북마크를 직접 실행할 수 없습니다. 설치 페이지의 파란 버튼을 북마크바로 드래그하는 방식이 가장 간단합니다. 로더가 차단되면 **Standalone Downloader**를 사용하세요.

## 주요 기능

- 첫 화면에서 Starlight(`sr`), Stardust(`ξ`), Satellite(`sl`), Stella(`st`), NEW GENERATION Normal(`▽`), Insane(`▼`) 선택.
- 선택한 표의 실제 데이터에 존재하는 레벨만 개수와 함께 표시.
- 오른쪽 위에서 한국어·日本語·English 전환.
- BMS Library의 Songs와 Sabuns 검색을 모두 사용.
- 완료된 검색 결과를 표·레벨별로 저장하고, 다음 실행에서 API 재검색 없이 즉시 복원. 중단된 검색은 저장된 지점부터 재개.
- 복합 필터 지원: **미다운로드/완료 확인**, **로컬 미설치/설치됨**, **높은 확률/검토/미매칭**은 서로 다른 조건 묶음끼리 동시에 적용. 같은 묶음에서는 하나만 선택되며 활성 버튼을 다시 누르면 해당 조건만 해제되고 **전체**는 모든 조건을 초기화.
- **현재 화면 전체 선택**으로 조합된 필터 결과를 한꺼번에 선택.
- Chrome/Edge에서 다운로드 폴더를 직접 선택해 스트리밍 저장. 같은 이름의 기존 파일은 덮어쓰지 않음.
- 고정 배치 크기 외에 **서버 허용량까지 (자동)** 처리 지원.
- 대기열, 제한 초기화 시각, 설정, 다운로드 완료 이력을 브라우저에 영구 저장.
- 페이지를 닫거나 다운로드 제한에 걸려도 첫 미완료 파일부터 재개.
- 폴더 쓰기 완료 또는 브라우저 저장 확인 항목을 `song:<파일 ID>` 또는 `sabun:<파일 ID>`로 저장하여 중복 다운로드 방지.
- 다운로드 이력 창에서 **다시 받기**, 기록 삭제, CSV 내보내기 지원.
- 이전 `starlight-level-downloader:*:v2` 대기열과 설정 자동 이전.
- 실행 및 빌드 외부 의존성 없음.

## 사용자 설치

프로젝트의 [GitHub Pages 설치 페이지](https://yuupmu.github.io/BMS_starlight_difficulty_downloader/)에서 **★ BMS Table Downloader** 버튼을 브라우저 북마크바로 드래그합니다. 그다음 [BMS Library Songs](https://horieyuuka.github.io/Songs)를 열어 북마크를 실행합니다.

설치 페이지에는 두 가지 방식이 있습니다.

- **Hosted loader:** GitHub Pages의 최신 스크립트를 불러오는 짧은 북마크입니다.
- **Standalone:** 전체 코드를 북마크 안에 포함합니다. 페이지 보안 정책 때문에 외부 스크립트 로더가 차단될 때 사용할 수 있습니다.

## GitHub Pages 공개

`docs/` 폴더에 빌드된 설치 페이지가 이미 포함되어 있습니다.

1. GitHub 저장소를 만들고 이 프로젝트를 업로드합니다.
2. **Settings → Pages**를 엽니다.
3. **Deploy from a branch**를 선택합니다.
4. `main` 브랜치와 `/docs` 폴더를 선택합니다.
5. 저장한 뒤 생성된 Pages 주소를 엽니다.

설치 페이지가 현재 주소를 기준으로 스크립트 URL을 자동 생성하므로 사용자명과 저장소명을 코드에 적을 필요가 없습니다.

## 개발 및 빌드

Node.js 20 이상을 권장합니다.

```bash
npm test
npm run check
npm run build
```

Stardust·Satellite·Stella 공식 JSON 스냅샷을 최신화할 때는 `npm run sync:tables`를 실행합니다. 이 세 소스는 브라우저의 교차 출처 접근을 허용하지 않아 `docs/data/`에 출처 그대로 복제합니다.

`npm run build`는 외부 패키지가 필요 없는 `scripts/build.mjs`를 사용하여 다음 파일을 만듭니다.

```text
dist/starlight-difficulty-downloader.js
dist/SHA256SUMS.txt
docs/assets/starlight-difficulty-downloader.js
```

생성된 번들은 직접 수정하지 말고 `src/`의 모듈을 수정한 다음 다시 빌드하세요.

## 이어받기와 중복 방지 방식

대기열과 완료 이력은 BMS Library 도메인의 `localStorage`에 저장됩니다.

**저장 폴더 선택** 모드에서는 파일 응답과 디스크 쓰기가 정상적으로 끝난 뒤에만 이력에 기록하고 대기열에서 제거합니다. 브라우저 기본 다운로드 모드에서는 한 파일을 전달한 뒤 **저장 확인**을 기다리며, 사용자가 확인하기 전에는 대기열에서 제거하거나 다음 파일로 넘어가지 않습니다. 이 확인 대기 상태는 페이지를 다시 열어도 유지되지만 임시 다운로드 URL 자체는 저장하지 않습니다.

완료 확인된 행도 다시 선택할 수 있습니다. **선택 → 대기열**에 완료 파일이 포함되면 작은 경고창을 한 번 표시하며, 확인한 경우에만 해당 완료 이력을 해제하고 다시 대기열에 추가합니다.

차분이 별도로 존재하는 채보는 곡 본체와 차분의 두 파일이 필요할 수 있습니다. 이때 진행 상황은 `1/2 완료 확인`처럼 표시됩니다.

검색 결과도 같은 `localStorage`에 표·레벨별로 저장됩니다. 같은 레벨의 **검색** 버튼을 다시 누르면 저장 결과를 불러오며, **새로 검색**을 누를 때만 캐시를 지우고 API 검색을 처음부터 실행합니다.

## 로컬에 설치된 채보 확인

도구 상단의 **BMS 폴더 검사** 버튼을 누르고, 압축을 풀어 둔 BMS 곡 폴더들을 포함하는 최상위 폴더를 선택합니다. 도구는 디스크 전체나 선택한 폴더 밖을 읽지 않으며, 선택한 폴더 내부를 재귀적으로 탐색해 `.bms`, `.bme`, `.bml`, `.pms` 차트 파일만 검사합니다. 파일 내용과 경로는 업로드하지 않고 브라우저 안에서 SHA-256과 MD5를 계산해 난이도표의 해시와 비교합니다.

검사가 완료되면 정확히 일치하는 채보를 **설치됨**으로 표시하고, 설치된 항목을 일괄 선택과 대기열에서 제외합니다. **로컬 미설치**와 **로컬 설치됨** 필터도 사용할 수 있습니다.

- 외딴 폴더도 그 폴더 자체나 그 상위 폴더를 직접 선택하면 검사할 수 있습니다. 선택한 폴더 밖의 파일은 인식하지 않습니다.
- 파일명이나 폴더명을 바꿔도 차트 파일 내용이 같으면 해시가 같으므로 인식합니다.
- 차트 내용을 수정하거나 확장자를 지원하지 않는 형식으로 바꾸면 인식하지 못할 수 있습니다.
- ZIP, RAR, 7z 등 압축파일 내부는 검사하지 않습니다. 압축을 푼 곡 폴더를 선택해야 합니다.
- 다운로드 폴더와 검사 폴더는 서로 독립적입니다. 새로 다운로드하거나 이동한 파일은 검사 범위에 포함한 뒤 **BMS 폴더 다시 검사**를 실행해야 반영됩니다.
- 첫 검사는 모든 차트의 해시를 계산합니다. 이후 같은 폴더를 다시 검사하면 상대 경로·크기·수정 시각이 동일한 파일의 저장된 해시를 재사용합니다.

브라우저 보안상 북마클릿이 임의의 디스크나 폴더를 자동으로 읽을 수 없으므로 사용자가 검사할 폴더를 직접 선택해야 합니다. 곡 폴더 구조를 평탄화하면 BMS 내부의 상대 오디오·이미지 경로가 깨질 수 있으니 기존 구조를 유지하세요.

## 저장 폴더와 자동 다운로드

Chrome/Edge에서는 **저장 폴더 선택**으로 이번 실행에서 사용할 폴더를 고를 수 있습니다. 이 모드에서만 여러 파일 자동 배치를 실행하며, 실제 응답을 읽어 빈 파일·HTML/JSON 오류 문서·전송 길이 불일치를 거부합니다. 쓰기가 실패하면 생성 중이던 부분 파일을 제거하고 현재 항목을 대기열 맨 앞에 유지합니다. 전송을 재시도할 때는 이미 발급된 다운로드 URL을 우선 재사용해 서버 허용량의 중복 소모를 줄입니다.

브라우저 보안상 도구는 전체 로컬 경로를 읽거나 임의의 경로를 문자열로 지정할 수 없으며, 페이지를 다시 연 뒤에는 권한 확인을 위해 폴더를 다시 선택해야 할 수 있습니다. 직접 저장이 지원되지 않는 브라우저는 한 번에 한 파일만 브라우저로 전달합니다. 파일이 실제로 저장됐으면 **저장 확인**, 보이지 않으면 **같은 링크 다시 열기**를 사용하세요. **새 링크 요청**은 기존 링크가 만료된 경우에만 사용해야 하며 서버 다운로드 허용량을 추가로 소모할 수 있습니다.

배치 크기의 **서버 허용량까지 (자동)**은 서버가 응답으로 알려 주는 현재 창의 잔여량을 따라 처리하고 0이 되면 대기열을 보존한 채 멈춥니다. 자동 배치는 저장 폴더 모드에서만 활성화됩니다.

### 중요한 제한

저장 폴더 모드의 완료는 파일 쓰기 완료를 도구가 확인한 상태입니다. 브라우저 기본 다운로드의 **저장 확인**은 사용자가 직접 확인했다는 뜻이며, 웹페이지가 브라우저 다운로드 완료를 기술적으로 검증한 것은 아닙니다. 확인 전에 페이지를 닫아도 해당 항목은 대기열에 남습니다.

## 저장되는 정보

도구는 다음 설정과 동작 정보만 브라우저에 저장합니다.

- 선택한 언어, 난이도표, 표별 레벨;
- 한 번에 받을 개수;
- 남은 대기열;
- 서버가 반환한 제한 잔여량과 초기화 시각;
- 완료 확인한 파일의 종류, ID, 제목, 레벨, 시각과 완료 방식(폴더 쓰기 검증/브라우저 사용자 확인/기존 요청 기록);
- 최근 표·레벨별 검색 결과(최대 8개 캐시);
- 검사한 로컬 차트의 상대 경로, 크기, 수정 시각, SHA-256/MD5 해시와 선택한 폴더 정보.

로컬 차트 인덱스는 BMS Library 도메인의 IndexedDB에만 저장됩니다. 별도의 프로젝트 서버는 운영하지 않으며, 이 정보나 파일 내용을 다른 곳으로 업로드하지 않습니다.
