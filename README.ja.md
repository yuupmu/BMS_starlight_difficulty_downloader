# BMS 難易度表ダウンローダー

[한국어](README.ko.md) · **日本語** · [English](README.md)

6つのBMS難易度表から表とレベルを選び、BMS Library から曲本体と差分を検索し、順番にダウンロード要求を行う多言語ブックマークレットです。

## かんたんインストール

1. [インストールページ](https://yuupmu.github.io/BMS_starlight_difficulty_downloader/)を開きます。
2. ブックマークバーが隠れている場合は `⌘/Ctrl + Shift + B` を押します。
3. **★ BMS Table Downloader** または **★ Standalone Downloader** をブックマークバーへドラッグします。
4. [BMS Library Songs](https://horieyuuka.github.io/Songs)を開き、追加したブックマークをクリックします。

GitHub の README ではブラウザーのセキュリティ上、`javascript:` ブックマークを直接実行できません。インストールページのボタンをブックマークバーへドラッグする方法が最も簡単です。ローダーがブロックされる場合は **Standalone Downloader** を使用してください。

## 主な機能

- 最初の画面で Starlight、Stardust、Satellite、Stella、NEW GENERATION Normal / Insane を選択。
- 選択した表に実際に存在するレベルと譜面数を表示。
- 右上で 한국어・日本語・English を切り替え。
- BMS Library の Songs と Sabuns の両方を検索。
- 表・レベル別に検索結果を保存し、API を再検索せず復元。中断した検索も続きから再開。
- 複合フィルターに対応: **未ダウンロード/保存確認済み**、**ローカル未導入/導入済み**、**高確度/要確認/未一致**は異なる条件グループ同士で同時に適用。同じグループでは一つだけ選択され、選択中のボタンを再度押すとその条件だけ解除、**すべて**ですべての条件を初期化。
- **表示中をすべて選択**で、組み合わせたフィルター結果をまとめて選択。
- Chrome/Edge では保存先フォルダーを選び、同名ファイルを上書きせず直接保存。
- 固定件数に加えて**サーバー許容量まで（自動）**を選択可能。
- キュー、制限解除時刻、設定、ダウンロード完了履歴をブラウザーに保存。
- ページを閉じたり制限に達した場合も、最初の未処理ファイルから再開。
- フォルダー書き込み完了またはブラウザー保存確認を `song:<ファイル ID>` または `sabun:<ファイル ID>` として記録し、重複を防止。
- 履歴画面から **再ダウンロード**、履歴削除、CSV 出力が可能。
- 以前の `starlight-level-downloader:*:v2` キューと設定を自動移行。
- 実行時・ビルド時ともに外部依存パッケージなし。

## ユーザー向けインストール

プロジェクトの [GitHub Pages インストールページ](https://yuupmu.github.io/BMS_starlight_difficulty_downloader/)を開き、**★ BMS Table Downloader** をブラウザーのブックマークバーへドラッグします。その後、[BMS Library Songs](https://horieyuuka.github.io/Songs) を開いてブックマークレットを実行します。

インストーラーには二つの方式があります。

- **Hosted loader:** GitHub Pages 上の最新スクリプトを読み込む短いブックマークレット。
- **Standalone:** 全コードをブックマーク内に含みます。ページのセキュリティポリシーで外部ローダーがブロックされる場合に利用できます。

## GitHub Pages で公開

ビルド済みサイトは `docs/` に含まれています。

1. GitHub リポジトリを作成してこのプロジェクトをアップロードします。
2. **Settings → Pages** を開きます。
3. **Deploy from a branch** を選択します。
4. `main` ブランチと `/docs` フォルダーを選択します。
5. 保存後、公開された Pages URL を開きます。

インストーラーは現在の Pages URL からスクリプトのアドレスを自動生成するため、ユーザー名やリポジトリ名を編集する必要はありません。

## 開発・ビルド

Node.js 20 以上を推奨します。

```bash
npm test
npm run check
npm run build
```

Stardust・Satellite・Stella の公式 JSON スナップショットは `npm run sync:tables` で更新できます。

生成物:

```text
dist/starlight-difficulty-downloader.js
dist/SHA256SUMS.txt
docs/assets/starlight-difficulty-downloader.js
```

生成されたバンドルは直接編集せず、`src/` を編集してから再ビルドしてください。

## 中断再開と重複防止

キューと完了履歴は BMS Library オリジンの `localStorage` に保存されます。

**保存先フォルダーを選択**モードでは、ファイル応答とディスク書き込みが正常に完了した後だけ履歴へ記録し、キューから削除します。ブラウザー標準ダウンロードでは1件を送信した後に **保存を確認** を待ち、ユーザーが確認するまではキューから削除せず次へ進みません。この確認待ち状態はページを開き直しても維持されますが、一時ダウンロード URL 自体は保存しません。

完了確認済みの行も再選択できます。**選択 → キュー**に完了済みファイルが含まれる場合は警告を一度表示し、確認した場合だけ完了履歴を解除してキューへ再追加します。

差分が別ファイルの譜面では、曲本体と差分の二つが必要な場合があります。進行状況は `1/2 完了確認` のように表示されます。

検索結果も表・レベル別に `localStorage` へ保存されます。**検索**は保存結果を復元し、**再検索**はキャッシュを消して最初から検索します。

## ローカルに導入済みの譜面を確認

ツール上部の **BMS フォルダーを検査** ボタンを押し、展開済みの BMS 曲フォルダーを含む最上位フォルダーを選択します。ディスク全体や選択範囲外は読みません。選択したフォルダー内を再帰的にたどり、`.bms`、`.bme`、`.bml`、`.pms` の譜面ファイルだけを検査します。内容やパスはアップロードせず、ブラウザー内で SHA-256 と MD5 を計算して難易度表のハッシュと比較します。

完了すると完全一致した譜面を **導入済み** と表示し、一括選択と保留中のキューから除外します。**ローカル未導入** と **ローカル導入済み** のフィルターも利用できます。

- 離れた場所のフォルダーでも、そのフォルダー自体または親フォルダーを選択すれば検査できます。選択範囲外は認識しません。
- ファイル名やフォルダー名を変更しても、譜面内容が同じならハッシュが同じため認識します。
- 譜面内容を編集した場合や、対応外の拡張子に変更した場合は認識できないことがあります。
- ZIP、RAR、7z などの圧縮ファイル内部は検査しません。展開済みの曲フォルダーを選択してください。
- ダウンロード先と検査対象は独立しています。新しくダウンロードまたは移動したファイルは検査範囲に含め、**BMS フォルダーを再検査** を実行すると反映されます。
- 初回は全譜面のハッシュを計算します。以降、同じフォルダーを再検査すると、相対パス・サイズ・更新日時が変わっていないファイルの保存済みハッシュを再利用します。

ブラウザーの安全仕様により、ブックマークレットが任意のディスクやフォルダーを自動的に読むことはできません。検査対象はユーザーが選択する必要があります。曲フォルダーを平坦化すると BMS 内の相対音声・画像パスが壊れる可能性があるため、元の構成を維持してください。

## 保存先と自動バッチ

Chrome/Edge の **保存先フォルダーを選択**では、今回の実行で使うフォルダーへ直接保存できます。このモードでのみ複数ファイルの自動バッチを実行します。空ファイル、HTML/JSON エラー文書、転送サイズ不一致を拒否し、書き込み失敗時は部分ファイルを削除して現在の項目をキュー先頭に保持します。転送の再試行では発行済み URL を優先的に再利用し、サーバー許容量の重複消費を抑えます。

ブラウザーの安全仕様により完全なローカルパスは表示されず、ページを開き直した後は再選択が必要な場合があります。未対応ブラウザーでは1件ずつブラウザーへ送信します。保存できた場合は **保存を確認**、見当たらない場合は **同じリンクを再度開く** を使用してください。**新しいリンクを要求** は既存リンクが期限切れの場合だけ使用し、サーバー許容量を追加消費する可能性があります。

**サーバー許容量まで（自動）**はサーバーが返す残数に従い、0 になった時点でキューを保持して停止します。自動バッチは保存先フォルダーモードでのみ有効です。

### 重要な制限

保存先フォルダーモードの完了は、ツールがファイル書き込みの完了を確認した状態です。ブラウザー標準ダウンロードの **保存を確認** はユーザー自身の確認を意味し、ウェブページが保存完了を技術的に検証したものではありません。確認前にページを閉じても、その項目はキューに残ります。

## 保存される情報

- 選択した言語、難易度表、表ごとのレベル;
- 1回の処理件数;
- 未処理キュー;
- サーバーが返した残数と解除時刻;
- 完了確認したファイルの種別、ID、タイトル、レベル、時刻と完了方式（フォルダー書き込み確認／ブラウザーのユーザー確認／旧要求履歴）;
- 最近の表・レベル別検索結果（最大8件）;
- 検査したローカル譜面の相対パス、サイズ、更新日時、SHA-256/MD5 ハッシュ、および選択したフォルダー情報。

ローカル譜面のインデックスは BMS Library オリジンの IndexedDB にのみ保存されます。本プロジェクトは独自サーバーを運用せず、この情報やファイル内容を外部へ送信しません。
